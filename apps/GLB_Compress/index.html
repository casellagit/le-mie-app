Riduci il peso del modello 3D mantenendo il formato GLB standard. Nessuna compressione geometrica Draco o Meshopt.

01 / Modello originale

Trascina qui un file .glb oppure fai clic per selezionarlo

02 / Ottimizzazione

Le texture ridimensionate mantengono il formato JPEG o PNG originale; non si applicano codec aggiuntivi. Seleziona “Mantieni texture originali” per evitare qualsiasi ricodifica delle immagini. Il rapporto di triangoli è un obiettivo, non una garanzia.
